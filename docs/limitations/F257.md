- **F257. What the skipped list says of an item that is still here, and what it does not**
  (`konedrive-tree/src/query.rs` `skipped`, `waiting_below_unplaced`, `counts`;
  `dbus/org.konedrive.Folder.xml` `Skipped`; `konedrivectl/src/text/files.rs` `still_here_text`;
  `app/synccontroller.cpp` `stillHereText`) — `Skipped()` is `a(sss)`: the path as OneDrive has the
  item, the reason, and what keeps it on this computer (empty when it is not here).
  - **What keeps it is what the last cycle found**, stored with the deferred change. It is the
    first thing found, not a list, and is as old as the last cycle: a row that went since is still
    counted until the next one. An item that began to wait through an upload's commit says only
    that it is still here, until a cycle looks.
  - **The line names the item as OneDrive has it**, not where it is on this computer; the path of
    what keeps it is a path on this computer.
  - **An item still here that OneDrive has inside a folder that is not placed** (moved into the
    Personal Vault) is a line of its own beside that folder's, with the folder's reason. A folder
    that waits and an item inside it that waits too are two lines.
  - **Until its change is taken the item is counted in `ItemsPlaced` and in `SkippedCount`.** The
    count is walked once per cycle that changed the tree (F167).
  - **The two wordings are kept in step by hand**: `still_here_text` and `stillHereText` have a
    test each, and nothing compares them, as `skip_reason_text` and `whyText` are compared.
  - **What is inside a folder that waits has no line of its own**, also when it could not be
    placed either: the folder's line covers it.
  - **One sentence stands for everything an examination has still to record** (made, changed,
    renamed, moved or deleted at the path named).
  - **No notification** is shown for a folder that waits (decided).
