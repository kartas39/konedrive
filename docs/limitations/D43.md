- **D43. `konedrived` depends on itself to give its tests the account's test support.** DEBT,
  *measured* (`cargo build --release -p konedrived` builds without the module; the tests under
  `konedrived/tests/` build with it), open. `konedrived::account::testing` (`MemoryWallet`, a
  wallet in memory, and `single_account`, one account with no accounts manager) is behind the
  feature `testing`, so that no shipped build carries it (quality finding `AC8`). The tests
  under `konedrived/tests/` are crates of their own and need it, and a crate cannot turn a
  feature of its own on for its tests, so `[dev-dependencies]` names `konedrived` itself with
  the feature, as `konedrive-dbus` does (D44); `konedrivectl`'s tests and `tests/vm` name the
  feature too. Nothing checks that a shipped build is made without it: in a build of the
  workspace's tests the feature is on, and a `cargo build` of the programs alone leaves it off
  only because no `[dependencies]` entry names it. `sync::testing` is behind another feature,
  `fault-injection` (D37).
