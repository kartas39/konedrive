- **D43. The test support of `account/` is built into the daemon's crate, always.**
  DEBT · reasoned, open (quality finding `AC8`). `konedrived::account::testing` holds what only
  tests use: `MemoryWallet`, a wallet in memory, and `single_account`, one account in a
  configuration of its own with no accounts manager. Unlike `sync::testing` (D37), which is
  compiled only under the crate's own tests and the `fault-injection` feature, it is compiled
  into every build, the packaged one included: the tests of `konedrived/tests/` and of
  `konedrivectl/tests/` are crates of their own that build the daemon's library without a
  feature, and the VM suite uses the wallet too. Nothing in the daemon calls it; it costs a few
  hundred bytes of code nobody runs. Before, both were in the production files themselves
  (`account/secret.rs`, `AccountService::single`).
