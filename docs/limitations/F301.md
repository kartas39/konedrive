### F301. Only the user who runs the daemon reaches the sync folder

- **Why:** The kernel lets nobody but the user who mounted it into a FUSE mount, root included,
  unless the mount has `allow_other`, which an ordinary user may set only when root has allowed it
  in `/etc/fuse.conf`.
- **Effect:** A backup or an indexer that runs as root or as another user, and `sudo` in the
  folder, get "permission denied" for the folder itself.
- **Stays because:** Nothing of konedrive runs as root or changes the system's configuration.
- **Where:** `crates/konedrived/src/mount/item_mount.rs` (`serve`); `SECURITY.md`
