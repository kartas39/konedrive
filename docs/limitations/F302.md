### F302. A removal made here is sent to OneDrive with no local trash and no confirmation

- **Why:** OneDrive keeps what is removed in its own recycle bin. A trash inside the folder would
  be uploaded, and a hold that waits for a confirmation depends on a window being open.
- **Effect:** A file or a whole directory tree removed in the sync folder is removed in OneDrive as
  any other change is sent, however many files it holds. It is got back from OneDrive's recycle
  bin, on the web; nothing of it is kept on this computer.
- **Stays because:** We chose one recycle bin, OneDrive's, over a second one here that would have
  to be kept in step with it.
- **Where:** `crates/konedrived/src/mount/item_write_operations/remove.rs`,
  `crates/konedrived/src/mount/upload_rules.rs`
