- **D40. Two tests of `remote/listing/` wait by the clock where they cannot see the event.**
  DEBT · reasoned, open (quality findings `RE10`, `RE12`).
  - `replacements::tests::a_stop_waits_for_a_swap_under_way_and_the_swap_is_said` used to read a
    private field of `Listing` to know that the stop had been asked before it let the swap go on.
    Nothing public says that, so it now sleeps 300 ms and checks that the stop has not returned.
    On a machine too busy to start the stop within 300 ms the test still passes, and then shows
    only that the swap ended and was said, not that the stop waited for it.
  - `poller::tests::the_poll_waits_longer_while_the_socket_is_up_and_not_once_it_drops` used to
    set the poller's "socket is up" flag by hand (`Poller::live_up`, public for this test). It now
    brings the fake OneDrive's notification socket up and drops it, and counts delta requests
    over real time: none in 1.5 s while the socket is up, two or more in 1.5 s at a 400 ms
    interval once it is down. The second count can come short under heavy load (see D31).
