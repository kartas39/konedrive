### F47. Removing an account leaves undownloaded files as empty placeholders

- **Why:** Removal forgets the folder and deletes the account's data, but never touches the folder's
  files.
- **Effect:** Files never downloaded stay with their names and sizes and read as zeros. Rescued
  files stay too, grouped by the account's id, not its name.
- **Stays because:** We decided that nothing konedrive does deletes a user's file (decisions.md,
  removing an account).
- **Where:** `docs/design/accounts.md`
