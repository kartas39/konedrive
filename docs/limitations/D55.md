- **D55. The enumeration of local acts has no act that makes something unreadable, and one
  act for damaged marks** (`konedrived/src/local/tests/acts.rs`) — DEBT, *reasoned*, open.
  - Its model checks every object through its path (content, the id mark) after each look, and
    an object set to mode `000` cannot be checked that way; the act would also be skipped when
    the tests run as root. What is listed for an unreadable file or directory, and that the
    line goes, is in the focused tests of `local/tests/passed_over.rs` only: no combination
    with a second act, a rebuilt store or an interrupted scan.
  - `DamageMarks` takes the state mark off the downloaded file `a.txt` (30 combinations): the
    item stays the item, gets no row, and is listed. Marks damaged on a file that is not
    downloaded, on a copy, or to a value no version writes are not enumerated; a copy and a
    wrong value are in the focused test.
