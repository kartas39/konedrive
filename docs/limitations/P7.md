### P7. Some OneDrive items are never placed in the folder

- **Why:** OneDrive closes the Personal Vault behind a separate sign-in and gives notebooks no
  content, Linux limits a name to 255 bytes and forbids some names, and the daemon reserves its own
  name prefix.
- **Effect:** These items are skipped and listed with the reason; they never appear as files. A name
  of 128 or more Cyrillic characters is one of them.
- **Stays because:** OneDrive and the filesystem decide all but the reserved prefix, which we keep
  for the daemon's working files.
- **Where:** `crates/konedrived/src/folder/classify.rs`
