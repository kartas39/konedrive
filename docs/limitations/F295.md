### F295. "Open in OneDrive" opens under whichever personal account the browser is signed in to

- **Why:** OneDrive's web keeps one personal Microsoft account per browser session. The item's
  address names the drive (`cid`), not who signs in; a `login_hint`, a sign-in page with a return
  address and the site's own account switcher all leave the session as it is.
- **Effect:** With two personal accounts, the page of an item of the account the browser is not
  signed in to says there is no access. The user signs in as that account in the browser first.
- **Stays because:** No address chooses the account, and all personal accounts share one tenant.
  A browser or a profile per account was turned down: the user would have to remember which is
  signed in where.
- **Where:** `crates/konedrived/src/sync/queries.rs` (`web_url`); issue #110
