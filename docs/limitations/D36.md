### D36. A store of another version, or a lost one, is rebuilt

- **Why:** Every change of the store's layout has a number, and a build reads only the layout of
  its own number. A store is never brought from one layout to another.
- **Effect:** After an upgrade that changes the layout, a downgrade, or the loss of the store's
  file, OneDrive is listed again in full and the rows are made again from the backing directory.
  Lost with the old store: the pins, the activity log, the conflict list, open upload sessions, and
  every unsent change that left nothing on disk (a removal, a move).
- **Stays because:** The store is a map that can be made again from OneDrive and the disk; a
  migration step for each layout would be code that runs once and can lose data when it is wrong.
- **Where:** `crates/konedrive-tree/src/schema/old_store.rs`
