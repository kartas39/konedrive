### D36. An older build rebuilds a store written by a newer build

- **Why:** Every change of the store's layout has a number, and an older build cannot read a layout
  it does not know.
- **Effect:** After a downgrade the folder is listed again in full. Changes not yet sent are lost (a
  pending delete comes back), and the activity log and conflict list are emptied.
- **Stays because:** An old build cannot know what a newer layout means, and guessing would risk
  wrong data.
- **Where:** `crates/konedrive-tree/src/schema.rs`
- **Also:** A stored kind that no build can read is read as a file, on purpose: an error there would
  leave the folder failing with nothing that heals it, and a rebuild would cost the waiting changes.
