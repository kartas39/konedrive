- **F10. A degraded root** (a directory the helper could not mark, or a root it could not cover
  at its start) is logged, not shown over D-Bus. The log is the only record: the helper keeps
  no list of such roots (`konedrive-helper/src/registration.rs` `record_walk`, for a walk;
  `main.rs` `cover_root`, and `main` for a root that now overlaps another). It kept a set of their ids, written at every walk and read by nothing; that
  set is gone (quality finding `HE6`), and what is logged is unchanged. Showing the condition
  to the user needs a message of the helper's protocol that says it, and the daemon passing
  it on.
