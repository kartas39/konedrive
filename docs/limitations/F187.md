### F187. A program holding a file open can lose writes when OneDrive removes it

- **Why:** The kernel lets a program keep writing into a file that has been removed, and has no
  error that says the file is gone.
- **Effect:** A write that arrives after our last look goes into a removed file and is lost, and a
  download in progress inside the removed item fails with an input/output error. A file found
  changed or open for writing is kept and uploaded as new.
- **Stays because:** We check for writers before removing; the moment between that check and the
  removal cannot be closed.
- **Where:** `crates/konedrived/src/remote/materialize/removal.rs`
