### F298. A change made in the folder on disk while the daemon is not running is not a move or a removal in OneDrive

- **Why:** At its start the daemon compares the backing directory with its store one place at a
  time, and does not guess what a person did there meanwhile: a copy, a backup that was put back
  and a power loss leave the same picture as a move or a removal.
- **Effect:** A file of OneDrive moved by hand is a new file at its new place, and the item is
  shown again at its old one. A file of OneDrive removed by hand is shown again, not on disk.
  Nothing is removed or moved in OneDrive. An edit that keeps a file's size and its time in whole
  seconds is not seen.
- **Stays because:** A wrong guess would remove or move the file in OneDrive and on every other
  device. To move or remove in OneDrive, the daemon runs.
- **Where:** `crates/konedrived/src/mount/backing_directory_check/disk_finding.rs`
