### F39. An upload cannot tell OneDrive its size up front

- **Why:** A personal drive answers an upload session that declares the file size with an error,
  although Microsoft documents the field.
- **Effect:** A full drive shows itself only when a piece of the upload is refused. An empty file
  needs a second request to set its time; if that fails, the file keeps OneDrive's time.
- **Stays because:** OneDrive decides what a session request may carry.
- **Where:** `crates/konedrive-graph/src/drive/upload.rs`
