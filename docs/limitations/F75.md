### F75. A truncate by path and a write through a mapping are not seen

- **Why:** The kernel raises only a modify event for a truncate by path and no event for a mapped
  write, and we do not subscribe to modify events.
- **Effect:** Such a change is not uploaded until the next full local scan: a daemon start, a helper
  reconnect or an event overflow.
- **Stays because:** Subscribing to modify events would wake the watcher on every write of every
  file, and mapped writes would still raise nothing.
- **Where:** `crates/konedrived/src/local/watcher/fan.rs`
