### K1. Dolphin opens some files just to show them, which downloads them

- **Why:** Dolphin reads a file's content to find its type when the name does not settle it, and to
  draw previews larger than the cached ones.
- **Effect:** Files with no or an unknown extension download when their directory is shown. Images
  and videos are spared up to 512 px because their previews come from OneDrive.
- **Stays because:** KDE decides how the type is found; an attribute naming the type is ignored
  (measured, KIO 6.30).
- **Where:** `docs/kio-behavior.md` §C
