- **K27. A file OneDrive refuses a thumbnail for has none, so Dolphin with previews on downloads
  it.** LIMIT · measured in the journal (issue #80). OneDrive answers `406 Not Acceptable` to
  `c512x512` for some items; the filler then asks once for Graph's named size `large` (up to
  800 px) and scales that down. An item refused at both sizes — or answered with any other 4xx but
  `401`, `408` and `429` — is recorded (`thumb_key`) and not asked for again until it changes, so
  it gets no thumbnail from the cloud: Dolphin with previews on opens the file to draw one, and that
  downloads it (K1). Turning previews off for the folder avoids it. Before issue #80 such an item
  was asked for again after every sync cycle, thousands of times a day, each time in a transfer
  slot. `sync::thumbs::tests::a_406_refused_at_both_sizes_is_recorded`. open.
