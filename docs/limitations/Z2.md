### Z2. A placeholder moved into a just-created directory can read zeros

- **Why:** The kernel reports a new or renamed directory only after the fact, so it cannot be held
  until the directory is covered.
- **Effect:** A script that makes a directory, moves a placeholder in and opens it within about 25
  ms reads zeros. The window is wider while the daemon or the helper is not running, and in a
  directory that cannot be watched (up to 10 minutes).
- **Stays because:** The kernel has no permission event for creating or renaming a directory.
- **Where:** `docs/design/hydration.md` §16
