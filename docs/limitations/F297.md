### F297. A range read of a file that is not on disk is not checked against the content's version

- **Why:** A program that reads a part of a file that is not on disk is given that range from
  OneDrive's download address. Graph's answer to a range names no version of the content, and a
  hash exists only for a whole file.
- **Effect:** When OneDrive replaces the content while a program reads the file in parts, a range
  of the newer content is not told from the one the program opened. A file downloaded whole is
  checked by its hash, and a range answered short fails the read.
- **Stays because:** Graph gives a range nothing to be checked against; the other choice is to
  download every file whole before its first byte is given.
- **Where:** `crates/konedrived/src/mount/item_range_fetcher.rs`,
  `crates/konedrived/src/content_source/graph_source.rs`
