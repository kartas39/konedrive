- **F286. What cannot be read is one line in Not Uploaded with one sentence for every cause,
  and the line goes only when its place is looked at again** (`konedrived/src/local/examine.rs`
  `decide`, `pass_over`; `local/examine/finish.rs` `tidy_skipped`; `konedrive-reason`
  `LocalSkip::Unreadable`) — what the line is, and where it stops:
  - **One reason for every cause.** `unreadable` is written for a file or directory whose
    attributes this daemon may not read by name (another user's file with mode `600`, a
    directory set to `000`), for an entry refused at an open or a strip after the listing (an
    immutable copy that kept its attributes), and for a downloaded file whose content gives
    `EIO` while it is hashed. The sentence says "cannot be read" and not which of these.
  - **A directory is one line.** Nothing inside it is named, and nothing inside it is counted:
    the line says "nor anything inside it". A directory that can be listed but not searched
    (mode `400`) gives one line for each name in it instead.
  - **The size is not always known.** A file that could not be read at the listing has no
    entry, so it adds nothing to the bytes of its reason; one passed over later adds its size.
  - **A name on the ignore list is left out** when the listing could not read the entry: only
    its name is known, and an ignored name without an item id stays local anyway. An item's own
    file whose name is ignored syncs as any item does; unreadable, it is not listed. An entry
    passed over after the listing is always listed.
  - **When the line goes.** In the first examination that looks at the place and finds it
    readable, or finds nothing there. That is: the look a change of mode or owner asks for
    (`FAN_ATTRIB`), the shared recheck (5 s to 600 s, F210), or a Full scan. What the listing
    could not read joins that recheck now, by its name and as a tree: a directory that can be
    read by then is listed with everything below it, which no run had looked at. So a line
    can outlast its cause by up to 600 s, and a place that stays closed is asked for every
    10 minutes for as long as it does, with the run's one warning in the journal each time.
  - **A directory deeper than `MAX_DEPTH` is still said only in the journal**, not in the list.
  - **An older daemon that opens the store** reads `unreadable` as a reason it does not know:
    shown as stored, among what waits.
