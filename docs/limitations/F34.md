### F34. A file OneDrive gives without a hash is downloaded unverified

- **Why:** The download is checked against the hash OneDrive supplies, and here there is none.
- **Effect:** The content is accepted as received and a warning goes to the log. Nothing is shown in
  the status.
- **Stays because:** OneDrive decides whether a hash exists; refusing the file would make it
  unreadable.
- **Where:** `crates/konedrived/src/hydration/source/guards.rs`
