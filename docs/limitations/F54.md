### F54. A local delete reaches OneDrive only when the helper proves it

- **Why:** Only root can open a file by its handle, and the kernel refuses even root for an object
  in a nested subvolume.
- **Effect:** With no helper, in a nested subvolume, or after the store was rebuilt, a deleted item
  stays in OneDrive and is placed in the folder again. Such an item is asked after every 30 seconds
  until an answer decides it.
- **Stays because:** Deleting on a guess would remove from OneDrive a file that was only moved away.
- **Where:** `crates/konedrived/src/local/liveness.rs`
