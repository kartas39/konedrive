- **A30. A daemon that stops between storing the token and listing the account loses the
  sign-in.** LIMIT · reasoned. A sign-in that adds an account stores the refresh token first, and
  takes the draft mark off `config.toml`, with the label set, after it. A daemon that stops in
  between comes up with an entry still marked as a draft, and removes it with its directory and its
  stored token, as it removes every draft at a start. No `SignInFinished` is sent for it. The user
  signs in again. Open.
