- **D56. The path of a descriptor, the resolve flags and "a name of ours" are written once for
  the daemon, but the helper keeps its own.** DEBT, *reasoned*, open.
  - One of each in the daemon: `konedrive_fs::proc_path`, `folder::disk::beneath`,
    `folder::walk::reserved`. `local/` uses them too.
  - The helper keeps its own on purpose (`konedrive-helper/src/registration.rs`, `marks.rs`):
    code that runs as root is not changed for tidiness. Its walk adds `RESOLVE_NO_XDEV` to the
    three flags, which the daemon's opens do not: the helper never marks across a mount point,
    and the daemon's walks (`folder/walk.rs`) compare device numbers instead.
  - `local/liveness.rs` `open_no_symlinks` resolves with two of the three flags
    (`RESOLVE_NO_SYMLINKS`, `RESOLVE_NO_MAGICLINKS`) and is not a copy of `beneath`: it opens an
    absolute path from the working directory, which `RESOLVE_BENEATH` would refuse.
