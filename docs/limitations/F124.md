### F124. A move between two accounts is a download, a removal and an upload

- **Why:** Each account's sync folder is a mount of its own, and the kernel refuses a rename from
  one mount to another. OneDrive cannot move an item between two accounts either.
- **Effect:** The program that moves the file copies it and removes the original: the file is
  downloaded, goes to the first account's recycle bin and is uploaded to the second as a new item.
  Item id, version history and sharing links do not follow it.
- **Stays because:** Neither the kernel nor OneDrive has a move that crosses the two.
- **Where:** the kernel (`rename(2)`, `EXDEV`); a mount for each folder:
  `crates/konedrived/src/mount/item_mount.rs`
