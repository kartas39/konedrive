### F124. A move between two accounts is a download, a delete and an upload

- **Why:** OneDrive cannot move an item between two accounts, so each account sees only its own
  half.
- **Effect:** The file can end up in both accounts, and a file deleted in the second account's
  folder right after the move comes back in the first. Item id and version history do not follow the
  file.
- **Stays because:** Every doubtful case is decided towards keeping the file, and a duplicate is the
  price.
- **Where:** `docs/design/writes.md` §8.3
