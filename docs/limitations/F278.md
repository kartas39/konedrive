- **F278. Where the one pass over the folder still differs by scope, and where the mode is still asked outside its questions**
  (`konedrived/src/remote/materialize.rs` `full`, `changed`; `remote/materialize/answers.rs`
  `left_alone`; `remote/materialize/removal.rs` `take_off`; quality finding `RE4`) — `full` and
  `changed` are written once for both modes, and the mode answers through the questions of
  `answers.rs`. Three things were kept as they were, because changing them would change what a
  cycle does:
  - **What phase 2 leaves alone is read from two sets.** A Full pass leaves what its scan found
    left (`Run::left`); a Changed pass leaves what its phase 1 found unsettled
    (`Pending::unsettled`). In a Full pass an item is unsettled without being left when the folder
    the base has it in waits and the scan did not find the item there; it is then placed, or
    waits by the rules of a missing item. One set for both would make it wait at once.
  - **An item removed in OneDrive whose removal waits for a mount** is marked left in a Full pass
    and only unsettled in a Changed one. In a Changed pass another item that moves to its name is
    therefore taken to the holding directory and put back, where a Full pass leaves it where it
    is. The end is the same; the object is renamed twice.
  - **What follows an item that can no longer be placed** is taken by the base only when the
    topmost item is (`after_placement`). A Full pass names as following what its scan found below
    the object; a Changed pass what the base has below the item and the new tree no longer
    places. Both now go through the one rule; that the two lists agree is not checked anywhere
    but by the enumeration.
  - **`take_off` asks the mode itself** (`self.mode.read_write()`, five times): its policy says
    why an object goes, and the mode what may stay, and the two were not folded into one.
    The functions only a read-write pass reaches still take the rules as `rw: &Rw`, handed down
    from the question that matched the mode.
