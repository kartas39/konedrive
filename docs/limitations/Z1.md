### Z1. When the helper crashes or is killed, every waiting open reads zeros; while none runs, nothing is intercepted

- **Why:** When the interception group closes, the kernel lets every open it still holds through.
  An ordinary stop (`SIGTERM`, `SIGINT`: a restart, an upgrade) answers them with an error first; a
  crash or a `SIGKILL` cannot.
- **Effect:** A program waiting for a download when the helper crashes or is killed reads zeros
  instead of the file. So does one whose open arrives between an ordinary stop's last read of the
  kernel's queue and the group closing. While no helper runs, files not downloaded read as zeros.
- **Stays because:** It is kernel behaviour; the only defence is that the helper must not die.
