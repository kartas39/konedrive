### Z1. When the helper stops, every waiting open reads zeros

- **Why:** When the interception group closes, the kernel lets every suspended open through.
- **Effect:** A program waiting for a download when the helper crashes, restarts, is upgraded or
  removed reads zeros instead of the file. While the helper is away, files not downloaded read as
  zeros.
- **Stays because:** It is kernel behaviour; the only defence is that the helper must not die.
- **Where:** `docs/design/hydration.md` §13
