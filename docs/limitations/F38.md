### F38. Finding pins means walking the whole folder

- **Why:** A pin is recorded only as an attribute on the file or folder, nowhere else.
- **Effect:** Every full reconcile, every start and every cycle that moves or removes something
  walks the folder again to find and count pins. A pinned download that keeps failing repeats that
  walk each cycle.
- **Stays because:** The store can be thrown away and rebuilt at any time, and pins must survive
  that.
- **Where:** `docs/design/pinning.md` §6
