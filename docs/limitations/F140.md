### F140. A read-only folder with changes waiting to upload stops following OneDrive

- **Why:** A read-only sync cycle would undo the local moves, renames and deletes that still wait to
  be uploaded.
- **Effect:** After a sign-out, an expired sign-in or any other unforced turn to read-only,
  OneDrive's changes do not reach the folder until the account is read-write again or the waiting
  changes are dropped by force. Files are still downloaded on open, and the last error says why.
- **Stays because:** The only other choice is to drop the user's waiting changes without asking.
- **Where:** `crates/konedrived/src/remote/listing/poller.rs`
