- **F281. A line of the "not uploaded" list inside a place that cannot be read stays until the
  place is read again** (`konedrived/src/local/examine.rs` `examined`;
  `local/examine/listing.rs` `Listing::examined`; `local/examine/finish.rs` `tidy_skipped`) — an
  examination takes a line off the list only for a place it looked at: asked for by the batch, not
  at or below a directory this daemon may not read, and not at or below an entry the run gave up

  read again and is examined. One function answers "was this place looked at" for the list, for
