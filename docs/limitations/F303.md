### F303. The executable bit of a file is kept on this computer only

- **Why:** OneDrive stores no Unix permissions of a file. The bit a `chmod` sets is written to the
  folder's store on this computer and nowhere else.
- **Effect:** The file is not executable on another computer, and not here once the folder is
  forgotten or its store is rebuilt ([D36](D36.md)): it must be set again. No other permission is
  kept: a `chmod 600` succeeds and changes nothing, and a file shows 0644, or 0755 with the bit.
  Other users of the computer cannot read the folder anyway: the mount is its owner's alone.
- **Stays because:** OneDrive decides what it stores of a file; carrying the bit there would need a
  field of ours on every item that other OneDrive clients do not read.
- **Where:** `crates/konedrived/src/mount/item_attributes.rs`
