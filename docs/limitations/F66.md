### F66. Consent to write stays with Microsoft after the account turns read-only

- **Why:** Microsoft keeps the consent for the Microsoft account, and only its own consent page
  takes it back.
- **Effect:** A read-only request may be answered with a token that can write. We use it to read
  only, never hand it out, and say so in the last error.
- **Stays because:** Microsoft decides what a refresh returns; we cannot revoke consent from our
  side.
- **Where:** `docs/design/writes.md` §2.2
