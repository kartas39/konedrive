### F74. Every change in a read-write folder must come from the daemon process

- **Why:** The kernel tells the watcher only the process id behind an event, and only for the
  watcher's own process.
- **Effect:** The daemon's own changes are recognised by that id and never examined from events. A
  change made by a child process or by the helper would look like the user's and be uploaded, so
  what the daemon itself creates must be handed to the examination directly.
- **Stays because:** The kernel gives an unprivileged watcher nothing else to tell changes apart.
- **Where:** `docs/design/writes.md` §3.2
