### A31. While a wallet prompt is open at the end of a sign-in, other account changes wait

- **Why:** The new account's token is stored while the lock on the accounts is held, and a wallet
  that has to be opened asks the user first.
- **Effect:** Until the prompt is answered, every other call that changes the accounts or the
  settings waits: another sign-in, removing an account, the client ID, the pause settings.
  Cancelling the sign-in does not wait.
- **Stays because:** Storing the token outside the lock would let a removal or a second sign-in
  run between the account's entry and its token.
- **Where:** `crates/konedrived/src/daemon/manager.rs`
