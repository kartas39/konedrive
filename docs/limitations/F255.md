### F255. A local-only file keeps a folder that OneDrive no longer has

- **Why:** A file with an ignored name is never uploaded, so the copy inside the folder is the only
  one.
- **Effect:** The folder stays on disk and is listed as skipped with the file's path until the user
  moves or deletes that file. Empty ignored files, symlinks, sockets and device nodes are removed
  with the folder.
- **Stays because:** Removing the folder would delete a file that exists nowhere else.
- **Where:** `crates/konedrived/src/remote/materialize/removal/unplaced.rs`
