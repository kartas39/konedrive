### F255. A file that is never uploaded keeps a directory that OneDrive removed

- **Why:** A file with an ignored name is never uploaded, so the copy in the sync folder is the
  only one.
- **Effect:** When OneDrive removes the directory such a file is in, the directory stays here with
  that file and is sent to OneDrive again as a new directory. What OneDrive had in it goes.
- **Stays because:** Removing the directory would delete a file that exists nowhere else.
- **Where:** `crates/konedrive-tree/src/sync_plan/removed_directory.rs`
