- **F275. What changed at a name between the listing and the act waits for the next look at that
  name** (`konedrived/src/local/examine/hands.rs` `Hands::open`, `strip`;
  `local/examine/detect.rs` `probe_writer`) — an examination lists first and acts afterwards, and it
  acts only on the object it listed: every open of a listed entry compares the descriptor with
  what was listed (the file handle, or device and inode where there is none). When the name holds
  another object by then, or nothing, the run does nothing there:
  - a copy whose marks were to come off keeps whatever now stands at its name untouched (the
    item's own file renamed over the copy keeps its marks). The name is marked as not
    examined for the rest of that run (`unreadable`, as for a copy that could not be
    stripped): nothing at it counts as missing, and nothing listed inside such a directory
    gets a row in that run;
  - a new file that went, or was replaced by another new file, gets no `create` row in that run.
    A `create` row it already had is not touched either: it stays for that run with the
    object that is gone, at that name. If the worker takes it meanwhile, its own look at the
    name finds another object than the row's and sends nothing (`upload/steps/shared.rs` `locate`); the next
    examination of the name puts the row right.
  The name is put into the run's recheck, so it is looked at again after `RECHECK` (30 s) at
  the latest; the user's own act also raises an event, whose batch normally comes first (2 s
  after the last change). Until then the new object at that name has no row: an upload that is
  a few seconds late, never a wrong one. What is not covered, and not the same for
  the two kinds: a directory's name that holds a file by then cannot be opened as a
  directory (`ENOTDIR`), which reads as "went", so it is looked at again like the rest; a
  file's name that holds a directory by then opens, is found not to be a regular file, and
  that is an error that is not the entry's own: it fails the batch as before (F210), which is
  offered again. FRAGILE · measured
  (`local::tests::since_listed`, through a Full local scan that is interrupted after its
  listing; the same code runs for a batch of names, which no test interrupts, D41). Open.
