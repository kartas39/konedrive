- **F272. A directory of the folder that cannot be read stops the sync of the whole folder** (`folder/disk.rs`, `Disk::scan`,
  `lock_tree`; `remote/listing.rs`, `take_turn`; quality finding `HY9`) — the scan is the
  reconcile's picture of the folder, and it is whole or it is an error.
  - **What was so already:** a directory set to mode `000` fails the scan at the look its
    parent takes at it (reading its item id needs read permission), and a directory that
    opened and could not be listed failed it too.
  - **What the one rule adds:** a directory that can be looked at and then not opened —
    `EIO`, `EMFILE`, a directory swapped for a link while the walk is on its way, an answer of
    a FUSE or network filesystem — fails the scan as well, where it was logged and left out
    as if it were empty: its files read as absent to the reconcile and to "does this folder
    hold anything yet" (`remote/listing/fetch.rs`, `holds_nothing_yet`). The error names the
    directory. A directory or an entry that went away during the walk (`ENOENT`, below the
    root) is passed over, for the open and for the listing. Depth beyond `MAX_DEPTH` is
    still passed over with a warning.
  - **The cost, as before for mode `000`:** a cycle that fails asks for a Full one next
    (`request_full`), which scans and fails the same way. So nothing arrives from OneDrive
    for the whole folder, not only for that directory, until it can be read. The user sees
    it in `LastError`, which names the directory; the way out is to make the directory
    readable again or to move it out of the folder.
  - **Putting the lock back does the opposite, on purpose** (`lock_tree`, a switch to
    read-only): a directory it cannot open or list and an entry it cannot look at are logged
    and passed over, and the root is locked. Since the root is locked, `ensure_locked`
    (`sync/mode.rs`) does not walk again, and that subtree stays without the lock, with a
    `warn` and nothing else, until a Full reconcile reaches it (`enforce_mode`) — which the
    point above says fails while the directory cannot be read.
