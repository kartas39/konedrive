### F193. A file saved by rename and moved at once loses its history

- **Why:** A save by rename makes a new file object, and until we examine it nothing ties that
  object to the item.
- **Effect:** When the save and a move to another directory both happen before our next look, the
  old item goes to OneDrive's recycle bin with its version history and the file is uploaded as a new
  item. No content is lost.
- **Stays because:** Items are tied to file objects, not names; a new object in another directory
  looks exactly like a new file.
- **Where:** `crates/konedrived/src/local/examine/missing.rs`
