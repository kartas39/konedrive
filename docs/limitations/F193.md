- **F193. A file saved by rename and then moved before any examination is deleted in OneDrive and
  uploaded as new** (`konedrived/src/local/examine/missing.rs` `missing_item`) — after an editor's
  save by rename the base keeps the old inode's handle until an examination rewrites it. If the
  file is moved to another directory before that, an examination of its old place asks after the
  old handle, finds it gone, and records a `delete` of the item; the file where it went carries no
  id, or a copied one, and goes up as new. The content is in OneDrive, as a new item; the old item is
  in OneDrive's recycle bin, and its version history stays with it. A narrow window: the save and
  the move both before any examination of the file. It was recorded for a move into a folder that
  was leaving; it never depended on that. FRAGILE · reasoned · open.
