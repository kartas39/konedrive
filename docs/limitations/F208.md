### F208. The helper caps each user at 32 folders and 8192 waiting opens

- **Why:** The helper runs as root for every user, and one user must not be able to exhaust it.
- **Effect:** A 33rd intercepted folder is refused, and opens beyond the cap fail with "try again".
  Waiting opens count against the file's owner, because the kernel's event does not name the
  opener's user.
- **Stays because:** Without the caps one user could take every descriptor the helper has.
- **Where:** `crates/konedrive-helper/src/roots.rs`
