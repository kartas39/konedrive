### F261. After the folder's filesystem changes, an unfinished move out is given up

- **Why:** File handles do not survive a new disk or a rolled-back snapshot, so the moved object can
  be found only at its last known path.
- **Effect:** If the object is not there, the item stays in OneDrive and is placed in the folder
  again. What was left outside is not tidied: a not-downloaded file there reads zeros once the
  helper restarts.
- **Stays because:** Nothing else names the object once its handle is dead.
- **Where:** `crates/konedrived/src/local/handles.rs`
