### R3. Removing the package does not refuse while a folder is registered

- **Why:** A package scriptlet that fails leaves the removal half done, so the package cannot
  refuse.
- **Effect:** The daemon is stopped and its mount is gone with it: the folder is left a plain
  directory without its write bits that shows the downloaded files, and the tool that could forget
  the folder and give the write bits back is gone with the package.
- **Stays because:** A half-removed package is worse; the user guide tells the user to forget the
  folder first.
- **Where:** `packaging/rpm/konedrive.spec`
