### R3. Removing the package does not refuse while a folder is registered

- **Why:** A package scriptlet that fails leaves the removal half done, so the package cannot
  refuse.
- **Effect:** The helper stops, files not downloaded read as zeros, and the tool that could forget
  the folder is gone with the package. The helper's list of folders stays on disk.
- **Stays because:** A half-removed package is worse; the user guide tells the user to forget the folder
  first.
- **Where:** `packaging/rpm/konedrive.spec`
