- **F269. What must hold before a file is emptied is the caller's word, for all but the lease** (`hydration/demote.rs`,
  `Held`, `demote`) — `demote` reads the state itself and empties only a file that reads
  `hydrating` or `dehydrating`, and it takes the write lease as a value, so a free-up or a
  recovery without one does not compile. Two things it cannot check and takes on trust:
  - that the file's ignore mark was cleared, or that none can be on it (`helper::Clearance`,
    asked by `dehydrate_opened`, `reset_interrupted` and the fill before it fetches);
  - `Held::Fill`: that the caller is the fill that wrote `hydrating`, under the per-inode
    lock (`roll_back`, `back_to_placeholder`). The lock is held through a task-local
    (`folder::locks::holding`, F230), which no type shows.
  A new caller that passes `Held::Fill` for a file it did not clear the way for would empty
  a file that may be ignore-marked only if that file read `hydrating`, a state the helper
  never marks; so the trust is in the order "clear, then fetch", which `Fill::run_on` keeps.
