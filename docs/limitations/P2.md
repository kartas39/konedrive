### P2. Opening a file while it is leased fails with "operation not permitted"

- **Why:** The helper's event descriptors are non-blocking, so the kernel refuses such an open
  itself instead of waiting for the lease.
- **Effect:** A program that opens a file in the milliseconds while its space is being freed, or
  while another program holds a lease on it, gets an error and must retry.
- **Stays because:** With blocking descriptors one leased file stops every intercepted open on the
  machine for up to 45 seconds, and any local user can cause that.
- **Where:** `docs/design/hydration.md` §4.3
