- **D44. `konedrive-dbus` depends on itself to test its private bus.** DEBT, *measured* (the
  crate's `tests/test_bus.rs` runs under `cargo test -p konedrive-dbus`), open.
  `konedrive_dbus::testing` (`TestBus`) is behind the feature `testing`, so that no shipped
  build carries it (quality finding `DB1`). The crate's own integration test needs it, and a
  crate cannot turn a feature of its own on for its tests, so `[dev-dependencies]` names
  `konedrive-dbus` itself with the feature. Every other user (`konedrived`, `konedrivectl`,
  `tests/vm`) names the feature the same way. Nothing checks that a shipped build is made
  without it: in a build of the workspace's tests the feature is on for every crate, and a
  `cargo build` of the programs alone leaves it off only because no `[dependencies]` entry
  names it.
