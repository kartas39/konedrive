### F72. A subvolume or mount inside the folder is not synced

- **Why:** The helper marks only directories on the same device as the folder it registered.
- **Effect:** Nothing there is uploaded, watched or filled from OneDrive; it is listed as skipped
  and the last error says so. A filesystem mounted over a directory that is already synced hides it,
  and its item stays in OneDrive undecided.
- **Stays because:** Syncing it needs the root helper to accept directories on other devices, a
  wider permission than we give it.
- **Where:** `crates/konedrived/src/local/examine.rs`
