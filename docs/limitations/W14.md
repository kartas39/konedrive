### W14. No desktop search inside a OneDrive folder

- **Why:** KDE's indexer reads file content, which would download the whole drive, and it has no
  names-only mode for one folder, so the folder is excluded from it.
- **Effect:** KRunner and Dolphin search find nothing in the folder. The check for an existing
  exclusion reads the indexer's settings file directly and depends on its current format.
- **Stays because:** KDE's indexer decides how it reads files; the only alternative is downloading
  everything.
- **Where:** `crates/konedrived/src/desktop/baloo.rs`
