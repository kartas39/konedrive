### F121. A move out is finished only when the object can be reached

- **Why:** The moved object is reached by its file handle through the helper and its place is read
  from the kernel, and either can be refused.
- **Effect:** The item stays in OneDrive and the row waits when the object is in a nested subvolume,
  owned by another user, not reachable by path, nameless after a reboot, or file leases are off. A
  cloud-only folder moved out is downloaded in full before anything is deleted.
- **Stays because:** Deleting in OneDrive before the content is proved to be local, outside the
  folder, could lose the only copy.
- **Where:** `docs/design/writes.md` §8
