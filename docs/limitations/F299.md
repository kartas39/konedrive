### F299. A directory that holds in OneDrive what the folder cannot show cannot be removed here

- **Why:** Removing a directory in OneDrive removes everything in it, also the items the folder
  never showed (P7), which the user did not see and did not ask to remove.
- **Effect:** `rmdir` of such a directory answers "directory not empty" though it looks empty. The
  files shown in it are removed as asked. The activity log names the directory, and
  `konedrivectl sync activity` says to remove it in OneDrive.
- **Stays because:** The other choices are to remove in OneDrive what was never shown, or to let
  the directory vanish here and come back.
- **Where:** `crates/konedrived/src/mount/item_write_operations/remove.rs`
