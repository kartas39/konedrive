### F172. An unfinished upload holds its name in OneDrive with an empty file

- **Why:** OneDrive creates an empty file when an upload session opens, refuses a second session for
  that name, and shows nothing that tells a live session from an abandoned one or which device
  opened it.
- **Effect:** A new file whose name is held by another device's or an abandoned session waits, and
  we never delete a holder we did not record. An empty file made in OneDrive at that name inside our
  own recorded window could be taken for ours and sent to the recycle bin.
- **Stays because:** OneDrive gives no way to identify the holder, so waiting is the only choice
  that never deletes someone else's upload.
- **Where:** `docs/design/writes.md` §6.1
