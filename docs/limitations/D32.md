- **D32. The tests' private bus has a configuration of its own, and only a test's own connection gives up on a call.**
  FRAGILE, *reasoned*, open. `konedrive_dbus::testing::TestBus` starts `dbus-daemon` with a
  configuration written by the test (`CONFIG` in `konedrive-dbus/src/testing.rs`), so that the
  bus reads no service directory and can start no installed program (quality finding `DB2`).
  - The configuration is a copy of the session bus's (`/usr/share/dbus-1/session.conf` of
    dbus 1.16) without its service directories, without what it includes (the legacy
    `/etc/dbus-1/session.conf`, `session.d`, `/etc/dbus-1/session.d`,
    `/etc/dbus-1/session-local.conf`, the SELinux contexts) and without the limits
    `service_start_timeout` and `max_pending_service_starts`, which have nothing to bound on
    a bus that starts no service. A change of the distribution's file does not reach it, and
    a test cannot see what the machine's additions would change.
  - It is a file in the temporary directory (`konedrive-test-bus-<16 hex digits>.conf`, the
    digits random; made new, for its owner only, another name taken if that one exists),
    removed as soon as the bus has printed its address. A test process killed in between
    leaves it; nothing collects such files.
  - `TestBus::connect` gives its connection a method timeout of 120 s (`METHOD_TIMEOUT`), so a
    call with no reply fails by name (quality finding `SY13`). A connection a test builds
    itself (`TestBus::builder`: the daemon's, a fake service's) has none, and neither has the
    `konedrivectl` binary a test runs, nor `konedrivectl` and the window on a user's bus: a
    call of theirs that gets no reply still waits for ever. The number is not measured; it
    is long so that a busy machine (D31) does not run it out.
  - The other private buses are not `TestBus`: the window's and Dolphin's tests have
    configurations of their own (`app/tests/session-bus.conf`, `dolphin/tests/`), and
    `tests/kio/run.sh` runs `dbus-run-session` with the session bus's configuration, service
    directories included.
