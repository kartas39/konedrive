    F53. Two of the rule's inputs it takes from the store after the first look, not from the
    model: which object the store records for each item, and where a waiting row last saw it. So a
    first look that recorded a wrong object would be judged by its own record. What is checked

    second (it held nothing), and a file deleted between the two is a `delete`.
