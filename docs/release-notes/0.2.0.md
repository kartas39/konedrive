The sync folder is now a FUSE mount that the daemon serves as you: nothing runs as root any more.
Your OneDrive is still a folder of files at their real sizes, and a file downloads when something
reads it.

This is still an alpha. Keep a copy of anything you cannot afford to lose.

## Upgrading from 0.1.1

A folder set up by 0.1.1 is not synced by this version. Before you upgrade, let every change you
made in the folder go up to OneDrive. After the upgrade the account says that its folder was set up
by an older version: remove the account, add it again and choose a new, empty folder.

## What changed

- **The folder is a FUSE mount.** Names come from the daemon's store, a file's content is fetched
  as it is read, and a copy, a rename or an edit inside the folder works as in any local folder.
  The root helper of 0.1.1 is gone.
- **Previews of PDFs and office documents** come from OneDrive, as those of images and videos do,
  so Dolphin no longer downloads them to draw a preview. A thumbnail deleted from the cache is made
  again, and the Activity page counts the thumbnails being downloaded.
- **A file in a folder that is always kept** can be freed up on its own.
- **A pinned file is not downloaded** while that would leave less free space than the account
  keeps.
- **A file keeps its executable bit.**
- **A change OneDrive does not allow**, for example in a folder shared with you to view only, is
  tried again by **Refresh**; it no longer asks you to sign in again.
- **Freeing up a file that is already freed up** succeeds, in Dolphin and in `konedrivectl`.
- A change to a file over 10 MiB that is already in OneDrive is uploaded.
- `konedrivectl` no longer waits for ever for a daemon that does not answer.

## Install

Fedora 44 or 45 with KDE Plasma 6, x86_64. Download the two packages for your Fedora — `.fc44` or
`.fc45` in the name, `konedrive` and `konedrive-kde` — and, in the directory they are in:

```
sudo dnf install ./konedrive-*.rpm
```

Then open **KOneDrive** from the launcher, sign in and choose an empty folder. The packages are not
signed. `SHA256SUMS` lists their checksums.

## Good to know

- Personal Microsoft accounts only; work and school accounts are not supported yet.
- What does not work and cannot simply be fixed is listed in `docs/limitations/`.
